This Informatica Tech Tuesday session explores a practical architecture for metadata-aware AI agents.

The session explains how Model Context Protocol can provide a secure bridge to governance metadata, allowing an agent to reason with current information about data sensitivity, quality, ownership, and policy. It also covers governance use cases, a metadata-aware agent architecture, and a demonstration of an agent working with Informatica Cloud Data Governance and Catalog.

Presented with Rashmi Prabhu and Shivam Saxena.
